# My Todo — GitHub Pages向けシンプルTodoアプリ

ログイン・同期・外部APIなしで動く、PC／スマホ両対応のTodoアプリです。

## 機能

- タスクの追加・編集・削除、完了／未完了
- 期限、優先度、カテゴリ、メモ
- 検索、表示フィルター、並び替え
- JSONバックアップの書き出し・読み込み（同じIDのタスクは上書き）
- 端末・ブラウザごとのローカル保存（IndexedDB）

## 使い方

1. GitHub Pagesに配置して、公開URLをブラウザで開くと利用できます（`file://` からの直接起動はブラウザによって保存機能が制限されることがあります）。
2. データは閲覧中のブラウザのIndexedDBに保存されます。
3. PCとスマホでデータは**同期されません**。
4. 別の端末に移す場合は「書き出し」でJSONを保存し、別端末の「読み込み」で取り込んでください。

## GitHub Pagesで公開

1. GitHubで `todo-app` などのリポジトリを新規作成します。
2. このフォルダーの `index.html` をリポジトリ直下に配置してコミットします。
3. GitHubのリポジトリ `Settings` → `Pages` で、公開元を `Deploy from a branch`、ブランチを `main`、フォルダを `/(root)` に設定します。
4. GitHub Pagesの公開URL（通常 `https://<ユーザー名>.github.io/<リポジトリ名>/`）から利用します。

## ご注意

- GitHub Pagesに置くのは**画面のファイルだけ**で、TodoデータはGitHubに送信しません。
- **ブラウザのデータ消去、プライベートブラウズ、端末故障などでデータが消えることがあります。** 定期的にJSONを書き出してください。
- データは暗号化していないため、共用端末での機密情報の登録は避けてください。
- 同じ端末でも異なるブラウザ、別のブラウザプロファイル、`file://` と GitHub Pages のURLはデータが別になります。
- サーバー、アカウント、外部ライブラリ、APIキーは不要です。

## ファイル
